# Папка для медиафайлов

Положите сюда ваши аудио и видео файлы:

## Аудио интервью
- **Покровский бульвар 6.m4a** — запись интервью с преподавателем
- Поддерживаемые форматы: `.mp3`, `.ogg`, `.wav`, `.m4a`

## Видео интервью
- **interview-video.mp4** — видеозапись интервью
- Поддерживаемые форматы: `.mp4`, `.webm`

## Как это работает
После добавления файлов в эту папку, они автоматически появятся в разделе «Интервью» на сайте.
Плееры будут работать без дополнительных настроек.

## Пример структуры
```
public/
  media/
    interview-audio.mp3
    interview-video.mp4
    README.md (этот файл)
```
