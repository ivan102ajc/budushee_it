# Инструкция по загрузке аудио и видео

## Проблема

Файлы с кириллическими именами и пробелами (например, "Покровский бульвар 6.m4a") могут не работать в браузере из-за проблем с URL-кодированием.

## Решение

### Шаг 1: Переименуйте файлы

**Для аудио:**
- Найдите ваш аудиофайл в папке `public/media/`
- Переименуйте его в: `interview.m4a`

**Для видео:**
- Найдите ваш видеофайл в папке `public/media/` (если он есть)
- Переименуйте его в: `interview-video.mp4`

### Как переименовать:

**В VS Code:**
1. Найдите файл в панели файлов слева
2. Правый клик → **Rename** (или нажмите `F2`)
3. Введите новое имя
4. Нажмите Enter

**В проводнике Windows:**
1. Откройте папку `public/media/`
2. Правый клик на файле → **Переименовать**
3. Введите новое имя
4. Нажмите Enter

**В Finder (Mac):**
1. Откройте папку `public/media/`
2. Правый клик на файле → **Переименовать**
3. Введите новое имя
4. Нажмите Enter

**Через терминал:**
```bash
# Для аудио
cd public/media
mv "Покровский бульвар 6.m4a" interview.m4a

# Для видео (если есть)
mv "ваш-видеофайл.mp4" interview-video.mp4
```

### Шаг 2: Проверьте структуру

После переименования структура должна быть:

```
ваш-проект/
├── public/
│   └── media/
│       ├── interview.m4a          ← аудиофайл
│       ├── interview-video.mp4    ← видеофайл (опционально)
│       └── README.md
├── src/
└── ...
```

### Шаг 3: Перезапустите сайт

```bash
# Остановите сервер (Ctrl+C)
npm run dev
```

### Шаг 4: Проверьте результат

1. Откройте `http://localhost:5173`
2. Перейдите в раздел «Интервью»
3. Попробуйте воспроизвести аудио
4. Нажмите «Показать видео» и проверьте видеоплеер

## Если всё ещё не работает

### Проверка 1: Файл существует?

Откройте в браузере:
```
http://localhost:5173/media/interview.m4a
```

- Если файл скачивается → путь правильный
- Если ошибка 404 → файл не в той папке или имя отличается

### Проверка 2: Консоль браузера

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Console**
3. Обновите страницу
4. Посмотрите на ошибки (красным цветом)

### Проверка 3: Формат файла

**Поддерживаемые форматы:**

**Аудио:**
- `.m4a` (рекомендуется)
- `.mp3`
- `.ogg`
- `.wav`

**Видео:**
- `.mp4` (рекомендуется, H.264)
- `.webm`
- `.ogg`

Если ваш файл в другом формате, конвертируйте его:
- Онлайн: https://cloudconvert.com
- Или используйте FFmpeg: `ffmpeg -i input.mov -c:a aac output.m4a`

### Проверка 4: Размер файла

Слишком большие файлы могут не загружаться. Рекомендуется:
- Аудио: до 50 МБ
- Видео: до 200 МБ

## Альтернативное решение: Используйте внешние ссылки

Если локальные файлы не работают, загрузите их на облачный хостинг:

### Вариант 1: YouTube (для видео)
1. Загрузите видео на YouTube
2. Получите ссылку: `https://www.youtube.com/watch?v=VIDEO_ID`
3. В коде замените `<video>` на `<iframe>`:

```tsx
<iframe
  src="https://www.youtube.com/embed/VIDEO_ID"
  className="w-full aspect-video rounded-xl"
  allowFullScreen
/>
```

### Вариант 2: Cloudinary (для аудио и видео)
1. Зарегистрируйтесь на https://cloudinary.com
2. Загрузите файл
3. Получите прямую ссылку
4. Вставьте ссылку в код:

```tsx
const AUDIO_PATH = 'https://res.cloudinary.com/your-cloud/video/upload/v123/interview.m4a';
```

## Частые ошибки

### Ошибка: "Failed to load resource: 404"
**Причина:** Файл не найден по указанному пути  
**Решение:** Проверьте имя файла и папку

### Ошибка: "Unsupported media type"
**Причина:** Браузер не поддерживает формат файла  
**Решение:** Конвертируйте файл в `.m4a` (аудио) или `.mp4` (видео)

### Ошибка: "CORS policy"
**Причина:** Файл загружен с другого домена  
**Решение:** Используйте локальные файлы или настройте CORS на сервере

После выполнения всех шагов:

✅ Сервер перезапущен (`npm run dev`)  
✅ Кэш браузера очищен (Ctrl+Shift+R)  
✅ Аудиоплеер отображается и воспроизводит звук

Если проблемы сохраняются, проверьте консоль браузера и пришлите скриншот ошибок.
