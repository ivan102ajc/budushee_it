# Папка public/videos

Положите сюда ваш видеофайл:

```
public/
  videos/
    video.mp4    ← ваш видеофайл
```

## Как загрузить видеофайл

1. Скопируйте файл `video.mp4` в эту папку (`public/videos/`)
2. После этого файл будет доступен по адресу: `/videos/video.mp4`

## Поддерживаемые форматы

- `.mp4` (рекомендуется, H.264)
- `.webm`
- `.ogg`

## Размер файла

Рекомендуется:
- Разрешение: 720p или 1080p
- Размер: не более 200 МБ для быстрой загрузки
- Кодек: H.264 для максимальной совместимости с браузерами
